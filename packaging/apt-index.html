ZapTV APT repository

A fast launcher for live TV channels on Linux. Current version: @VERSION@

Add the repository once, then ZapTV updates with the rest of your system:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://goarnko.github.io/zapper/zaptv.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/zaptv.gpg

echo "deb [signed-by=/etc/apt/keyrings/zaptv.gpg] https://goarnko.github.io/zapper ./" \
  | sudo tee /etc/apt/sources.list.d/zaptv.list

sudo apt update
sudo apt install zaptv

After that, sudo apt upgrade picks up new releases.

Prefer not to add a repository? Every release also has a .deb and an AppImage attached on the releases page.
